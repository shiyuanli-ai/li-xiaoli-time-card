# 李晓丽时间卡正式发布包

这个文件夹可以直接上传到静态网站服务，客户扫码后打开 `index.html` 即可查看时间卡。

## 文件说明

- `index.html`：客户扫码后看到的网页首页。
- `time-card/li-xiaoli-time-card.png`：时间卡高清长图。
- `time-card/li-xiaoli-time-card.pdf`：时间卡 PDF 版本。

## 正式二维码生成规则

二维码必须指向一个长期可控、微信可打开的网址，例如：

```text
https://你的品牌域名.com/lxl/
```

不要再使用：

```text
chatgpt.site
qrdemo.2020818.xyz
```

原因：这类临时或第三方测试域名可能被微信拦截，也不适合印刷进照片集。

## 员工发布步骤

1. 把整个 `li-xiaoli-time-card` 文件夹上传到静态网站服务。
2. 确认手机微信能打开上传后的 `index.html` 页面。
3. 用 WarmingQRCode 生成二维码：
   - 地址：https://wangmingxuan666.github.io/WarmingQRCode/
   - 输入正式网址。
   - 纠错级别选择 H。
   - 背景用白色，前景用黑色或深金色。
   - 下载 PNG。
4. 用微信扫码测试：
   - 能打开页面才可以印刷。
   - 如果显示被拦截，说明是网址问题，不是二维码图片问题。
5. 二维码一旦印刷，不要再改网址；后续只改网页内容。

## 推荐托管顺序

1. 品牌自有域名 + 腾讯云/阿里云静态网站：最适合正式销售。
2. GitHub Pages：适合测试或低成本发布，需确认微信能打开。
3. 飞书公开链接/腾讯文档公开链接：适合临时过渡，不建议作为长期印刷链接。
